# AI usage disclosure

I used an AI assistant in VS Code (Copilot SDK) to inspect the assignment and starter kit, implement
and test the Python API/agent/MCP/RAG code and React interface, and draft the documentation and
evaluation runner. I reviewed the changes, ran the tests and build, and am responsible for all
submitted code and claims.

One incorrect implementation suggestion I caught: the first risk-scoring pass assigned a prompt
injection signal a score below the skip threshold. The focused injection test reproduced that a job
could still be recommended despite the signal. I changed the risk thresholding so the injection is
flagged as high risk and verified the job is skipped.

No generated evaluation results were copied from other work. The baseline smoke results are
generated by `python -m evals.runners.run_demo_eval`; local simulator outcome results are generated
by `python -m evals.runners.evaluate_gigsim` using deterministic synthetic client preferences and
outcomes. Neither result set represents observed marketplace performance.
